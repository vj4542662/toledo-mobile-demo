# Toledo Mobile · demo

Speelbare demo van [Toledo Mobile](https://github.com/vj4542662/toledo-mobile) met een fictieve student (Lotte Vermeulen). Alle gegevens zijn verzonnen; er wordt niets naar KU Leuven of KURT gestuurd.

- `index.html`: de demo-pagina met iPhone-kader (op een gsm schermvullend).
- `app.html`: laadt `mock.js` (nepgegevens en nep-API's) en `tm.js` (het echte script, aangepast zodat het op een gewone webpagina draait).
- `tm.js` wordt gebouwd met `make_demo.py` uit de broncode van Toledo Mobile.
